# 字幕清理工具 subtitle-cleaner

純前端的字幕／逐字稿清理工具，將口語錄音轉寫稿中的語助詞、重複詞、確認理解類句子自動清理或標記，協助人工後製校稿。

## 特色

- **單檔執行**：純 HTML + CSS + 原生 JavaScript，瀏覽器開啟即可使用
- **無後端**：所有處理皆在本機完成，不會上傳檔案
- **支援格式**：`.txt`（每行一句）與 `.srt`（保留時間軸）
- **自訂規則**：可新增取代詞，並匯出 / 匯入 JSON

## 使用流程

1. 在左側貼上字幕文字，或點 **📂 選擇檔案** 載入 `.txt` / `.srt`
2. 勾選想啟用的自動規則
3. 視需要新增自訂取代規則
4. 按 **▶ 開始掃描**
5. 在右側審閱，必要時編輯或刪除個別行
6. 點 **匯出 ▾** 下載清理後的字幕，或匯出修改前後對照表

## 自動規則說明

### 1. 拿掉語助詞（`r_particles`）

#### 自動移除（句首 / 句中 / 句尾皆處理，允許疊字）
```
嗯  啊  哦  喔  噢  唉  欸  呃  額  哈
呵  哇  哎  吼  呦  呐  喲  唷  呀  嗯哼
```

#### 僅句尾移除（避免誤刪詞中字，如「啦啦隊」）
```
囉  啦  唄
```

> 句中語助詞會直接刪除，**不會補上任何標點符號**。

### 2. 標記確認理解類語句（`r_understand`）

不會自動刪除，僅標為待審。共 **25 條判斷規則**：

- **固定句型**（17 條）：理解嗎、了解嗎、瞭解嗎、聽懂嗎、懂我的意思嗎、知道嗎、明白嗎、清楚嗎、這樣（子）懂/明白/清楚、有沒有問題/疑問、跟上了嗎、跟得上嗎、記住了嗎、學會了嗎⋯⋯
- **句尾型**（8 條）：懂嗎？對不對？有沒有？OK？好嗎？是不是？對吧？是吧？

另外，句尾出現 `呢`、`嘛`、`吧` 時也會掛上 **⚑ 語氣詞** 待審徽章（因為這三個會改變語意，保留人工判斷）。

### 3. 移除重複詞語（`r_repeat`）

僅針對下列 7 個白名單詞彙：

```
然後  所以  就是  那個  這個  因為  其實
```

例如「然後然後然後」→「然後」。

### 4. 處理首尾空白與多餘換行（`r_trim`）

- 每行 trim 首尾空白
- 連續半形空白壓成 1 個
- 整段最前最後的空行清除
- SRT 內部換行保留不動

## 自訂取代規則

- 在「原文」「取代為」欄位輸入後按 **＋** 新增
- 取代邏輯為**字串完全比對**（非正則）
- 取代為留空 = 直接刪除該字串
- 可匯出為 JSON 檔備份，或從 JSON 載入分享給他人

## 匯出格式

| 選項 | 檔名 | 說明 |
|---|---|---|
| 匯出清理後文字（TXT 模式） | `cleaned_subtitle.txt` | 每行一句 |
| 匯出清理後文字（SRT 模式） | `cleaned_subtitle.srt` | 保留原時間軸，重新編號 |
| 匯出修改前後對照 | `subtitle_diff.txt` | 列出所有修改 / 刪除的紀錄 |

所有檔案皆以 UTF-8 BOM 開頭，避免 Windows 記事本誤判編碼。

## 右側面板互動

| 操作 | 結果 |
|---|---|
| 點 ✏️ | 編輯該行（Enter 儲存、Shift+Enter 換行） |
| 點 ✕ | 標記刪除 |
| 點 ↩ | 還原已刪除行 |
| 全部 / 待審閱 / 已刪除 | 切換檢視篩選 |

### 待審徽章顏色

| 顏色 | 徽章 | 含義 |
|---|---|---|
| 🟠 橘色 | ⚑ 語氣詞 | 句尾出現 `呢` / `嘛` / `吧`，可能改變語意 |
| 🟣 紫色 | ⚑ 確認理解 | 命中「理解嗎、了解嗎、OK 嗎⋯」等 25 條句型 |

## 實戰教學

### 範例 1：純文字逐字稿

**輸入**：
```
那個那個我們今天要講的是嗯這個重點啊
那大家有沒有問題？
然後然後我們繼續下一個主題啦
```

**勾選**：拿掉語助詞 ✅、標記確認理解 ✅、移除重複詞 ✅、處理空白 ✅

**結果**：

| # | 顯示 | 徽章 |
|---|---|---|
| 1 | 那個我們今天要講的是這個重點 | （無，已自動清理） |
| 2 | 那大家有沒有問題？ | 🟣 確認理解 |
| 3 | 然後我們繼續下一個主題 | （無，已自動清理） |

匯出後第 2 行需要你決定要不要保留（按 ✕ 刪除或不動），其他兩行直接套用。

---

### 範例 2：SRT 字幕

**輸入**（含 HTML 標籤的常見格式）：
```
1
00:00:01,000 --> 00:00:03,500
<font color="#fff">那個欸我先說一下哦</font>

2
00:00:03,600 --> 00:00:06,000
這樣懂嗎
```

工具會自動：
1. 偵測為 SRT 模式
2. 剝除 `<font>` 標籤
3. 套用語助詞規則

**結果**：

| # | 文字 | 徽章 |
|---|---|---|
| 1 | 我先說一下 | （清理過） |
| 2 | 這樣懂嗎 | 🟣 確認理解 |

匯出 SRT 時會**保留原時間軸**，並從 1 重新編號。

---

### 範例 3：自訂取代規則

情境：講師習慣說「ㄚ那個」，想替換成「然後」。

1. 在左側下方輸入：原文 `ㄚ那個` → 取代為 `然後`
2. 按 **＋** 加入清單
3. 按 **💾 儲存規則** 匯出 JSON 備份
4. 下次開新逐字稿時 → **📂 選擇規則檔案** 一鍵載入

> 自訂規則為**純字串比對**，不支援正則表達式。

## 常見問題 FAQ

### Q1：載入 SRT 後內容是亂碼？
工具預設以 **UTF-8** 讀取。若你的 SRT 是 Big5 / GBK 編碼，請先用記事本「另存新檔」改成 UTF-8 再載入。

### Q2：明明勾了「拿掉語助詞」，為什麼某些字沒被移除？
請對照 README 中的清單。常見漏網之魚：
- **句尾的 `呢` / `嘛` / `吧`** → 不自動刪，只會標為 🟠 語氣詞 待審
- **疊字詞中的字**（如「啦啦隊」「哈密瓜」）→ 規則只在句尾或前後有標點/空白時才會吸收

### Q3：清理完文字變成空白怎麼辦？
代表整行都是語助詞被掃光了（例如「嗯嗯嗯」）。目前**不會自動刪除空行**，匯出時會留下空行。建議：
- 在右側手動按 ✕ 刪除該行，或
- 切到「待審閱」/「已刪除」篩選一次處理

### Q4：自訂規則沒生效？
- 確認是否**完全字串比對**：規則「啊」不會匹配到「啊啊」（雖然語助詞規則會抓）
- 自訂規則套用順序：在語助詞規則**之前**執行（[SPEC.md](SPEC.md) §5）
- 如果規則 `from` 和語助詞規則衝突，最終結果可能是兩個規則交互作用後的樣子

### Q5：匯出對照表少了一些行？
對照表只列**文字被改過 或 被刪除**的行（[SPEC.md](SPEC.md) §8.5）。只有「待審徽章但沒改字」的行不會列入。

### Q6：可以保留 SRT 原始編號嗎？
目前不行，匯出 SRT 會從 1 重新編號。若需保留請改 [index.html](index.html) 第 775 行邏輯。

### Q7：可以批次處理多個檔案嗎？
目前不支援。一次只能載入一個檔案。若要批次處理，可分別載入後分別匯出。

### Q8：資料會上傳嗎？
**不會。** 工具是純前端，所有處理都在你瀏覽器內完成。只有[休眠中的 AI 功能](SPEC.md) 才會呼叫外部 API（目前介面已關閉）。
